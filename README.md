# Sus Link

Sus Link is a Discord bot that helps you investigate suspicious links without opening them on your own device. Right-click a message to check for phishing patterns, deceptive forms, redirects, and attempted downloads in an isolated cloud browser. Get a private threat report with a risk score, screenshots, and an AI assessment from Gemini.

Works in servers, DMs, and group DMs. Only the bot owner can run scans.

## Free tiers

[Instabox](https://instabox.sh/docs/limits) provides **one free machine**, which Sus Link reuses. The [Gemini API](https://ai.google.dev/gemini-api/docs/pricing) also offers a **free tier**, subject to model availability and quotas.

## Get started

1. [Create and install your Discord bot](docs/discord-setup.md). Enable **User Install** and choose **Add to my apps**.
2. [Add your API keys and start Sus Link](docs/setup.md).
3. DM the bot `!sync`, then right-click a message → **Apps → Sus Link Checker**.
